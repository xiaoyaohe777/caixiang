# 说明，在本项目右上角点击下载，解压运行.exe文件即可


本工具可以帮你快速计算相配分、相配五行分、宫位神分，省时省力，值得相宗内部有基础的弟子以及社会相师尝试。

各相师需要拿出自己的时间和实力来换取名利空间，本项目就是为各相师节省时间精力做的工具，要求相师们在熟练掌握采相流程的情况下，再说使用。

否则你的采相能力将长期没有任何长进，甚至倒退，被同门甩下一大截。

本人开发采相脚本，体会非常深刻，举例来说：你如果忽略了相主的相基和采相年日排列组合。那就是省忽略了潜在的龙虎门对标风险，从而陷入只看分数的危险境地。结果就是人家那一年高分低价值，你当作高分高价值来指导，还要求人家扩大规模，加紧生产。人家现实不说大灾大难，不死就算不错了。
